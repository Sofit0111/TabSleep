# 🚀 TabRest: Smart Memory Manager (Chrome Extension)

**TabRest** — это умное легковесное расширение для Google Chrome, разработанное на JavaScript Оно помогает оптимизировать использование оперативной памяти (RAM), отправляя неактивные вкладки в «спящий режим» (Tab Discarding) без потери их состояния.

В отличие от громоздких аналогов, TabRest работает на чистом JavaScript, не перегружает систему, защищает ваши данные в формах ввода и предоставляет детальную аналитику экономии ресурсов прямо в стильном Popup-интерфейсе.

---

## ✨ Основные возможности

### 💤 Управление вкладками и памятью

* **Усыпление в один клик:** Возможность мгновенно отправить в спящий режим текущую вкладку или все неактивные вкладки.
* **Мягкое пробуждение:** Все вкладки восстанавливаются автоматически при клике на них или массово через кнопку «Разбудить все».
* **Умное автоусыпление:** Фоновый таймер на базе `chrome.alarms` усыпляет вкладки через заданное время простоя.

### 🧠 Умные алгоритмы защиты данных

* **Защита форм ввода:** Расширение сканирует страницу перед усыплением. Если вы начали заполнять форму, пост или комментарий, вкладка останется активной.
* **Интеллектуальные исключения:** Автоматический пропуск закрепленных (pinned) вкладок и страниц, где воспроизводится аудио или видео.
* **Глобальный белый список:** Добавляйте любимые домены в список исключений, чтобы они никогда не засыпали.

### 📊 Продвинутый UI/UX и Аналитика

* **Встроенный менеджер вкладок:** Управляйте всеми открытыми вкладками (усыпить, разбудить, закрыть) прямо из окна расширения.
* **График экономии:** Визуализация сэкономленной оперативной памяти по дням недели на кастомном Canvas-графике.
* **Профили нагрузки:** Быстрое переключение между режимами:
* *Агрессивный* (сон через 3 минуты)
* *Баланс* (сон через 20 минуты)
* *Режим чтения* (автоусыпление отключено для лонгридов)


* **Адаптивный дизайн:** Современный минималистичный интерфейс с плавной анимацией и поддержкой темной и светлой тем.

### ⚡ Быстрый доступ (QoL)

* **Контекстное меню:** Кликните правой кнопкой мыши в любом месте страницы, чтобы мгновенно отправить её в сон или добавить домен в белый список.
* **Менеджер сессий:** Сохраняйте все открытые вкладки в один клик, закрывайте их для освобождения 100% памяти и восстанавливайте сессию, когда это необходимо.
* **Горячие клавиши:** Настраиваемые хоткеи для мгновенного управления без мыши.

## 🛠 Технологический стек

Расширение написано без использования тяжелых фреймворков (React/Vue) и сборщиков (Webpack/Vite), что гарантирует максимальную скорость работы и минимальное потребление ресурсов самим расширением.

* **Архитектура:** Google Chrome Extension API (Manifest V3)
* **Логика:** Vanilla JavaScript (ES6+, Модульная структура)
* **Фоновые процессы:** Service Workers + `chrome.alarms`
* **Интерфейс:** HTML5, CSS3 (Переменные, Flexbox, Grid, CSS-анимации)
* **Хранение данных:** `chrome.storage.sync` (для настроек) + `chrome.storage.local` (для статистики)

## 🚀 Инструкция по установке (Режим разработчика)

Так как расширение находится на этапе разработки, его можно установить локально всего за несколько шагов:

1. **Скачайте код:** Клонируйте этот репозиторий или скачайте архив с кодом и распакуйте его в отдельную папку на компьютере.
2. **Откройте управление расширениями:** В браузере Google Chrome перейдите по адресу `chrome://extensions/` (или откройте *Меню -> Дополнительные инструменты -> Расширения*).
3. **Включите режим разработчика:** В правом верхнем углу страницы активируйте переключатель **«Режим разработчика»** (Developer mode).
4. **Загрузите расширение:** В левом верхнем углу нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked) и выберите папку, в которой лежат файлы проекта (папка, содержащая `manifest.json`).
5. **Готово!** Иконка расширения появится в панели Chrome. Закрепите её для быстрого доступа.

## 📝 Важное примечание для тестирования

> ⚠️ **Ограничения Chrome API:** Google Chrome блокирует принудительное усыпление (`chrome.tabs.discard()`) для внутренних страниц браузера (например, `chrome://...`, страниц настроек или интернет-магазина Chrome). При тестировании расширения проверяйте его работу на обычных сайтах (например, GitHub, YouTube, новости). Для симуляции экономии памяти в статистике используется среднее значение в **70 МБ** на одну вкладку.
